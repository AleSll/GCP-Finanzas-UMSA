02 · Caso de estudio financiero

Contexto, alcance y justificación del modelo.

Modelo académico simulado

Distribución de recursos de una empresa tecnológica

Una empresa tecnológica debe planificar la asignación de su presupuesto entre cuatro áreas que compiten por recursos y mantienen relaciones operativas. La dirección necesita evaluar cómo cambian las asignaciones ante estabilidad financiera, estrés presupuestario y diferencias pronunciadas de escala entre áreas.

El modelo utiliza una función cuadrática convexa:

minimizar f(x) = ½ xᵀ A x − bᵀ x sujeto al sistema de optimalidad: A x = b

La matriz A representa pesos de costo, sensibilidad y acoplamiento entre áreas. El vector b representa prioridades o requerimientos ponderados. Al ser A simétrica definida positiva, la función es estrictamente convexa y existe un único minimizador. El modelo no impone restricciones adicionales de no negatividad ni una suma presupuestaria fija; por ello, se interpreta como un modelo de asignación linealizada y no como un presupuesto contable completo.

Supuestos y procedencia de datos

  • Los valores son datos sintéticos elaborados con fines académicos.
  • Las cuatro variables y sus unidades se mantienen en los tres escenarios.
  • Los coeficientes fuera de la diagonal representan interdependencias ponderadas.
  • El escenario de estrés modifica las prioridades financieras.
  • El escenario mal condicionado modifica la escala diagonal y el acoplamiento.
  • La solución de referencia se calcula con Cholesky, no se introduce manualmente.
Los datos no provienen de estados financieros reales ni de una empresa identificada.

05 · Análisis de los tres escenarios

Comparación del contexto financiero y su efecto matemático.

Escenario 1

Ideal

Se mantienen costos y prioridades equilibradas. La matriz está bien condicionada y la solución representa la asignación de referencia del caso estable.

A = A₁ b = [562, 834, 324, 302]ᵀ
Escenario 2

Bajo estrés financiero

Se reducen los recursos y las prioridades. La matriz se conserva y cambia b; por ello el punto de equilibrio se desplaza, pero el condicionamiento de A permanece igual.

A = A₁ b = [489, 698, 281, 253]ᵀ
Escenario 3

Mal condicionado

Se introducen escalas muy diferentes en la diagonal. El precondicionador Jacobi equilibra las escalas y puede mejorar la convergencia.

A = D C D b = [1595, 91300, 2331200, 62156000]ᵀ

Interpretación de consistencia

Los escenarios 1 y 2 comparten A para aislar el efecto de un cambio en las prioridades b. El escenario 3 modifica A de forma fundamentada para representar un sistema con escalas muy distintas. En los tres casos se conservan las mismas variables financieras.

06 · Solución numérica de referencia

Resolución directa mediante factorización de Cholesky.

Procedimiento

Para una matriz simétrica definida positiva se obtiene A = L Lᵀ. Luego se resuelven dos sistemas triangulares: L y = b y Lᵀ x = y. La solución resultante se utiliza como referencia para calcular los errores de GC y GCP.

A = L Lᵀ L y = b (sustitución hacia adelante) Lᵀ x = y (sustitución hacia atrás)

10 · Conclusiones y referencias

Interpretación técnica, financiera y bibliografía.

Conclusiones técnicas

  1. El método de Gradientes Conjugados es aplicable cuando la matriz del sistema es simétrica y definida positiva.
  2. El precondicionador de Jacobi utiliza la diagonal de A para equilibrar escalas y resolver Mz = r en cada iteración.
  3. La conveniencia del precondicionamiento debe evaluarse con los resultados de convergencia y no asumirse únicamente por su uso.
  4. El número de condición aporta información sobre la sensibilidad del sistema; un valor alto puede amplificar los efectos de errores numéricos o perturbaciones.
  5. La solución directa de Cholesky sirve como referencia para cuantificar errores y validar los métodos iterativos.

Conclusiones financieras

El escenario de estrés demuestra cómo una modificación de las prioridades ponderadas puede desplazar la asignación presupuestaria sin modificar el condicionamiento de la matriz. El escenario mal condicionado representa diferencias pronunciadas de escala entre áreas, por lo que resulta útil aplicar un precondicionador diagonal. Los resultados deben interpretarse como una simulación académica y no como una recomendación de inversión o asignación real.
